### Phase 2: OBJECT-ORIENTED PROGRAMMING (Days 6-12 | ~10 hours)
Learn: Classes, inheritance, modules
Do: Exercises 4.1 - 4.3
Goal: **Can structure code using OOP**

```ruby

  end

  end
```

## 📞 GETTING HELP

### When You Get Stuck

1. **Read the error message carefully**
   - Ruby errors are usually very descriptive
   - Line number tells you exactly where

2. **Google the error**
   - "Ruby: undefined method `xyz'" 
   - Stack Overflow usually has the answer

3. **Use IRB to experiment**
   - Test small pieces of code
   - See what works and what doesn't

4. **Read the documentation**
   - [Ruby Docs](https://ruby-doc.org/)
   - [Rails Guides](https://guides.rubyonrails.org/)

5. **Ask the community**
   - Ruby community is very helpful
   - Stack Overflow, Reddit (/r/ruby), local meetups
